# Plant Classification Application

This project is part of COMP4423 Computer Vision Assignment 2.  
It builds a plant recognition system using classical machine learning and a simple Streamlit app.

## Project Description
- Collected plant images with different angles, lighting, and backgrounds.
- Implemented feature extraction methods: Color Histogram, LBP, HOG.
- Trained and tuned models: SVM, Random Forest, XGBoost.
- Evaluated performance with accuracy, confusion matrix, and per-class metrics.
- Built a local Streamlit app for image upload and bilingual prediction .
